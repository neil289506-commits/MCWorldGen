功能總覽

MCWorldGen 的完整功能清單與技術架構。

四步驟精靈

Loader → 世界類型 → 資源匯入 → 執行與匯出。

⬇

自動安裝核心

下載並安裝對應載入器伺服器核心到暫存資料夾,解析啟動指令。

🌱

世界設定

世界類型、極限模式、獎勵箱、結構生成、種子碼。

📦

一鍵匯入資源

mods 複製到 mods/,datapack 複製到 level/datapacks/。

📺

即時 Console

轉發伺服器輸出,偵測 Done 後自動送出 stop。

🗜

BZIP2 打包

以 QuaZip 的 BZIP2 method 打成使用者指定的 zip。
