使用流程

選擇載入器與版本

Vanilla / Paper 單一選單;Fabric / Quilt 雙獨立選單;Forge / NeoForge 成對選單。

設定世界

世界類型、極限模式、獎勵箱、結構、種子碼。

選擇 mods / datapack

一鍵匯入,自動放入正確資料夾。

執行並匯出

即時 Console 顯示進度,完成後自動打包 zip。

自行建置

先 clone 專案:

git clone https://github.com/neil289506-commits/mcworldgen.git
cd mcworldgen
vcpkg install
cmake -B build -S . -DCMAKE_TOOLCHAIN_FILE=/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release

常見問題

需要什麼執行環境?

PATH 中要有 Java;另需 Python 3 與 requests 以抓取版本資料(Paper 例外)。

Forge 怎麼啟動?

MC ≥ 1.18.1 執行 installer 產生的 run.bat / run.sh,更舊版本啟動 universal jar。

預生成怎麼結束?

偵測到 "Done (" 後自動送出 stop 指令。
